# Classification Outputs

This folder contains the final output files for the Geodemographic Classification of Consumer Behaviour.

These files provide the classification mappings (Primary Cluster and Subcluster assignments) for all Lower Layer Super Output Areas (LSOAs) in England and Wales. 

## Provided Formats
- **CSV (`.csv`)**: Tabular mapping of LSOA codes to their respective clusters.
- **Shapefile (`.shp` etc.)**: Spatial polygons with the classification attached.
- **GeoPackage (`.gpkg`)**: A modern, single-file spatial format containing the same data as the shapefile.
